# jev-ios-bridge 1.2.0

jev-ios-bridge now checks Android apps too: Jetpack Compose, Compose Multiplatform and classic Views, on an Android 12 or later emulator. A script says `"platform": "android"` and names the app's package, and the run works as it does on iOS: scripted steps, screen claims judged by Jev, a log pane, and the same reports. The new `/test-android` skill writes and runs those scripts, and `jev-ios-bridge capture` shows what a run sees on screen. iOS scripts need no change.

## Install

With Claude Code:

```sh
claude plugin marketplace add hugues-vnsgn/jev-ios-bridge
claude plugin install jev-ios-bridge@jev-ios-bridge
```

The skills are `/jev-ios-bridge:test-ios` and `/jev-ios-bridge:test-android`. Claude Code asks for your TypeSafe key, a simulator UDID and an Android device (a serial or an AVD name). Only the key is required: leave the device you don't use empty. To change a value later, open `/plugin` and manage the plugin.

For the command line, Codex, or CI:

```sh
gh release download v1.2.0 -R hugues-vnsgn/jev-ios-bridge -p 'jev-ios-bridge-1.2.0.tgz'
npm install ./jev-ios-bridge-1.2.0.tgz
```

You need macOS, Node 24 or later, and a TypeSafe API key. For iOS, you need Xcode. For Android, you need the Android SDK's `adb` and a device on Android 12 (API 31) or later. Start with the [quickstart](https://github.com/hugues-vnsgn/jev-ios-bridge/blob/v1.2.0/docs/guide/01-quickstart.md), and for Android, [setting up an Android device](https://github.com/hugues-vnsgn/jev-ios-bridge/blob/v1.2.0/docs/guide/12-android-setup.md).

## What's new

- **Android scripts.** `app.package` names the app, and `app.activity` and `app.intentExtras` open a known screen. `device.avd` names an emulator and `device.serial` a phone, or the `JEV_ANDROID_DEVICE` setting names either.
- **The device agent.** The bridge drives the screen through its own copy of mobilecli's device agent, from the pinned `mobilecli` 1.0.14 package, checked against its SHA-256. It never runs mobilecli, so there is no telemetry and no cloud call, and it doesn't read other connected devices. If another UI tool (mobile-mcp, mobilecli, Appium, `uiautomator`) holds the device, the run refuses with `DEVICE_BUSY`: close that tool first.
- **One device lease for iOS and Android.** A run that finds a crashed run's lease takes it over and clears what that run left on the device.
- **The log pane** shows the app's logcat. A crash or kill ends the run with `APP_EXITED`, and a freeze with the new `APP_NOT_RESPONDING`.
- **`jev-ios-bridge capture`** prints the current screen, one JSON line per element, or Jev's text with `--jev`. It needs no TypeSafe key and never launches the app. Use it to write selectors.
- **`/test-android`,** the Android twin of `/test-ios`. When a Compose app has no identifiers, it tells you where to add `testTagsAsResourceId`.
- **Nine reason codes and new report fields,** added for Android runs only. iOS messages, reports and exit codes don't change.

The [CHANGELOG](https://github.com/hugues-vnsgn/jev-ios-bridge/blob/v1.2.0/CHANGELOG.md) has the details. Everything 1.0 froze stays the same: the script format, the CLI and MCP tools, the verdict rules, and the report and evidence layout. 1.2 only adds to them.

## Know before you start

- **Real Android phones are untested.** Every Android check below ran on emulators. `device.serial` accepts a phone, but no phone run was part of this release's checks. Problems found on phones go into 1.2.1.
- **Non-English typed values pass through the device clipboard.** The device agent types only ASCII, so the bridge pastes other text and then clears the clipboard. The keyboard may still keep the text as a suggestion, so don't type a real secret that way. ASCII values are typed key by key and never touch the clipboard.
- **Jev's accuracy promise covers English screens.** Non-English text types exactly, but Jev's judgments of non-English screens weren't measured.
- **Android runs were tried only on Apple silicon.** The copy of the device agent is checked on both Mac builds.
- The [limits](https://github.com/hugues-vnsgn/jev-ios-bridge/blob/v1.2.0/docs/guide/10-limits.md) page has the rest.
