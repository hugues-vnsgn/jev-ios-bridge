# v1.0.0

The first stable release of jev-ios-bridge. It checks iOS apps (SwiftUI, UIKit, and Compose Multiplatform) on a simulator: you write a script of steps and checkpoint claims, the bridge runs it through MobileBuildMCP, and TypeSafe's Jev judges each claim against the screen's text. The script format, CLI and MCP tools, verdict rules, and report and evidence layout stay compatible for all of 1.x.

## Install

```sh
gh release download v1.0.0 -R hugues-vnsgn/jev-ios-bridge -p 'jev-ios-bridge-1.0.0.tgz'
npm install ./jev-ios-bridge-1.0.0.tgz
```

You need macOS with Xcode, Node 24 or later, and a TypeSafe API key. Start with the [quickstart](../guide/01-quickstart.md). There's no npm registry release.

## What's new since 0.1.0

The frozen contract (`report.json`, script `"version": 1`, exit codes 0/1/2/3, and bridge-owned reason codes and roles) comes with golden-file contract tests. There's a live log pane of the app's own output, and `app.launchArgs` for debug entry points. A confidently false claim now fails beside uncertain ones. The bridge is faster: no `npx`, and concurrent screenshots. Device locks recover, and the data-handling fixes landed. There's a full guide, and the license is MIT. The [CHANGELOG](../../CHANGELOG.md) has the full list and the upgrade steps.

## Limits

- Simulators only; English screen text; printable US-keyboard typing.
- It can be slower than letting Claude drive the simulator directly.
- Compose Multiplatform before 1.12.1 can crash under accessibility polling.
- Checkpoint screen text goes to TypeSafe. Use test data in apps you control.

The full list is in [limits](../guide/10-limits.md) and [data handling](../guide/09-data-handling.md).
