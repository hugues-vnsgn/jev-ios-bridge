# v1.0.0

The first stable release of jev-ios-bridge. It checks iOS apps (SwiftUI, UIKit, and Compose Multiplatform) on a simulator: you write a script of steps and checkpoint claims, the bridge runs it through MobileBuildMCP, and TypeSafe's Jev judges each claim against the screen's text. The script format, CLI and MCP tools, verdict rules, and report and evidence layout stay compatible for all of 1.x.

## Install

```sh
gh release download v1.0.0 -R hugues-vnsgn/jev-ios-bridge -p 'jev-ios-bridge-1.0.0.tgz'
npm install ./jev-ios-bridge-1.0.0.tgz
```

You need macOS with Xcode, Node 24 or later, and a TypeSafe API key. Start with the [quickstart](../guide/01-quickstart.md). There's no npm registry release.

## What's new since 0.1.0

The frozen contract (`report.json`, script `"version": 1`, exit codes 0/1/2/3, and bridge-owned reason codes and roles) comes with golden-file contract tests. There's a live log pane of the app's own output, and `app.launchArgs` for debug entry points. A confidently false claim now fails beside uncertain ones. The bridge is faster: no `npx`, and concurrent screenshots. Device locks recover, and the data-handling fixes landed. There's a full guide, and the license is MIT. The [CHANGELOG](../../CHANGELOG.md) has the full list and the upgrade steps.

## Measured results

All from the release checks on 2026-09-26, on the reference Mac and dedicated simulator (iOS 26.4). [Evidence](https://github.com/hugues-vnsgn/jev-ios-bridge/tree/v1.0.0/spikes/benchmarks/results/v1.0.0).

| Check | Result |
| --- | --- |
| **Tests and contract tests** | 162 tests pass, including golden-file tests for every frozen surface, locally and in CI |
| **Benchmark verdicts** | Weather passed and Contacts passed, the same as 0.1.0. Reminders **passed**: its count claim scored exactly 0.90, against 0.87 (inconclusive) in 0.1.0. The claim is true, but it sits on the bound, and the owner accepted it as borderline. |
| **Speed** (prepared execution, one run each) | Weather 107.7 → 63.1 s (−41%); Contacts 74.8 → 54.7 s (−27%); Reminders 91.2 → 55.5 s (−39%) |
| **Compose Multiplatform** (a real 1.9.0 app, through its debug gallery shortcut) | All six scripts got their expected verdicts (4 passed, the planted false claim failed, the planted ambiguous guard came back inconclusive), with no production network request |
| **Clean install and quickstart** | Both entry points report 1.0.0, and the installed files match the package list. The quickstart works as written, including through Claude Code and `/test-ios`. |
| **Jev cost** | About $0.00016 per checkpoint, $0.0001–$0.0008 per run |

**Observation shape:** 1.0 sends `visible-full-text-v2`, which is v1 plus scroll-bar lines. It was adopted by a pre-registered test: 0 confidently wrong and 3/48 uncertain on the frozen corpus, against 4/48 for v1 in the same run. The gain is within run-to-run noise. Explicit empty values were rejected, because Jev called fields with withheld content empty at 0.97–0.98. [Results](../../spikes/benchmarks/results/v1.0.0/observation-shape/results.md).

**Capture reuse** (reusing MobileBuildMCP's post-action capture) is off. MobileBuildMCP reported a mid-transition screen as settled. [Evidence](../../spikes/benchmarks/results/v1.0.0/capture-reuse/README.md).

## Limits

- Simulators only; English screen text; printable US-keyboard typing.
- It can be slower than letting Claude drive the simulator directly.
- Compose Multiplatform before 1.12.1 can crash under accessibility polling.
- Checkpoint screen text goes to TypeSafe. Use test data in apps you control.
- After a pass, the log pane finishes, but Terminal keeps its window until you close it, unless its profile closes windows when the shell exits.

The full list is in [limits](../guide/10-limits.md) and [data handling](../guide/09-data-handling.md).
