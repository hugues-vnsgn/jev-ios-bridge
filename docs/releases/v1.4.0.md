# jev-ios-bridge 1.4.0

Adds experimental observed iOS actions through the CLI and MCP: prepare an allocation, inspect a screen, submit one authored tap, and retain the observed outcome. Observed actions do not use Jev or require a TypeSafe API key. Scripted and driven runs retain their existing authentication requirements.

## Changes

- Durable admission, cancellation, allocation identity and quarantine for uncertain actions.
- Explicit simulator/runtime selection, bounded simulator creation, app staging and artifact validation.
- Xcode and runtime metadata checks, including narrowly scoped read-only mount policies.
- Installed documentation for observed requests, migration, capacity and recovery. Observed actions remain experimental and require `JEV_EXPERIMENTAL_OBSERVED=1`.

## Validation and limits

The accepted code passed 2,258 tests on Node 24.0.0 and 26.8.1. Clean tarball/plugin package checks passed all 37 commands per Node with `npm_config_maxsockets=1`; guarded startup checks and independent code/package review passed. The compiled payload in this release is byte-identical to that accepted payload; release metadata and notes were updated afterward.

Actual iOS 27 metadata compatibility, operational configuration, migration and capacity checks passed. **The five planned live simulator acceptance cases and their final live review were not completed.** The owner elected to publish the accepted code/package scope and end the storage investigation. This release does not claim live acceptance for the new observed workflow.

## Install

```sh
gh release download v1.4.0 -R hugues-vnsgn/jev-ios-bridge -p 'jev-ios-bridge-1.4.0.tgz'
npm install ./jev-ios-bridge-1.4.0.tgz
```

For Claude Code, update the `jev-ios-bridge` marketplace and plugin, then restart Claude Code. Node 24 or later is required. Follow the installed observed-actions guide and its offline migration instructions before enabling effects.
