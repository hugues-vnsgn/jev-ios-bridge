# jev-ios-bridge 1.1.0

jev-ios-bridge is now a Claude Code plugin. Two commands install the MCP server and the `/test-ios` skill, and Claude Code asks for your TypeSafe key and simulator. Nothing to copy or register by hand. Scripts, reports, and the CLI work as in 1.0.

## Install

With Claude Code:

```sh
claude plugin marketplace add hugues-vnsgn/jev-ios-bridge
claude plugin install jev-ios-bridge@jev-ios-bridge
```

The skill is `/jev-ios-bridge:test-ios`. Your key goes into your system's secure storage, not a project file. To change either value later, open `/plugin` and manage the plugin.

For the command line, Codex, or CI:

```sh
gh release download v1.1.0 -R hugues-vnsgn/jev-ios-bridge -p 'jev-ios-bridge-1.1.0.tgz'
npm install ./jev-ios-bridge-1.1.0.tgz
```

You need macOS with Xcode, Node 24 or later, and a TypeSafe API key. Start with the [quickstart](https://github.com/hugues-vnsgn/jev-ios-bridge/blob/v1.1.0/docs/guide/01-quickstart.md).

## What's new

- **The Claude Code plugin,** `jev-ios-bridge-plugin-1.1.0.zip` on this release. The marketplace pins it by SHA-256. On install, Claude Code fetches the dependencies from the lockfile.
- **`JEV_PROJECT_DIR`.** Claude Code starts plugin servers in the plugin's own folder. The plugin sets this variable to your project, so evidence lands in your project's `.jev-runs/`. Unset, nothing changes.
- **Docs:** the quickstart installs the plugin, and the manual setup moved to [running](https://github.com/hugues-vnsgn/jev-ios-bridge/blob/v1.1.0/docs/guide/06-running.md#without-the-plugin).

The [CHANGELOG](https://github.com/hugues-vnsgn/jev-ios-bridge/blob/v1.1.0/CHANGELOG.md) has the details. Everything 1.0 froze stays the same: the script format, the CLI and MCP tools, the verdict rules, and the report and evidence layout.

## Checked before release

- 163 tests pass, locally and in CI. `claude plugin validate` passes for the plugin and the marketplace.
- A fresh dependency install from the zip took 1.9 s with an empty npm cache. Claude Code's limit is 60 s. MobileBuildMCP's AXe binary stayed executable.
- **The plugin, loaded in Claude Code 2.1.280, ran the quickstart's diagnostic app end to end.** It got the expected **failed** verdict: `Total: $5` scored 0.02 against the app's $3. The evidence landed in the project. The Claude cost was $0.18, with Sonnet.
- With no key set, the server doesn't start, and Claude Code names the missing setting.
