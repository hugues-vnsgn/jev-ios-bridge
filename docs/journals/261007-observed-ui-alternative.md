# Observed iOS actions without native-provider extension

The provider route was unavailable. The user chose to preserve unmodified apps
and accept visible outcome evidence with explicit uncertainty. Implemented a
standalone experimental tap runner over the existing MobileBuildMCP driver,
strict fresh target/guard checks, an opt-in no-retry path and durable admission.
Crashes, lost acknowledgements and uncertain results prevent replay and retain
quarantine. Provisional evidence files identify the journal as terminal authority.

Host checks: 33 focused tests; full check 962 tests plus typecheck and build.
Independent reviews found persistence/reporting ordering defects, now corrected.
Live simulator verification is outstanding; no claim of native certification or
completion of the 23 old production tickets. See
[verification](../../.scratch/observed-ui/verification.md) and
[usage](../../spikes/observed-ui/README.md).
