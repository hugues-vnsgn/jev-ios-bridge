Two notes the doc does not cover. First, `run.ts:417` masks typed values before rendering when a script has a `do` step. The corpus has no typed values, so the replay renders the snapshot unmasked, as a plain scripted checkpoint does. Second, ADR-0004's 300-judgment re-scoring obligation (line 95) applies. Both the iOS projection (v1 to v2) and the capture source (MobileBuildMCP to Appium) changed since those judgments.
