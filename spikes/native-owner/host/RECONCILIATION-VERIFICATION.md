is a separate Interface for the single registered numeric-boolean metadata
failure. The committed registry bytes are pinned by a literal SHA256. There is
no caller-supplied approval or case path. `_case_data` is a private test data
Seam; tests use independent synthetic receipts and actual temporary files.

The Module uses explicit private composition with `_Study` for deadline,
process ownership, file-backed output, command receipts and simulator identity.
The historical parent return code remains unknown. Success text does not become
an exit code; original invalid records, result, ledger and archive are unchanged.
The exception never claims native settlement or any production capability.

Inspection performs fresh read-only gates and produces a separate receipt.
Apply uses a permanent exclusive claim beside the original directory, registers
owner/evidence before tools, revalidates claim ownership, repeats provenance and
fresh process/path/hash gates, then permits one runner uninstall and restoration.
Uncertain/partial mutations retain their resource facts and a permanent claim.
Claim accounting can finish after expiry without extending tool admission.
